# JOWE MUTANT FX

Creative audio effects plugin by Jowe Beats.

## Platform
Windows VST3

## Framework
JUCE / Audio Plugin Coder

## Main Features
- FX Micro Bank
- 8 Micro Presets per Effect
- 16/32 Step FX Sequencer
- 8 Patterns (A-H)
- Glitch Engine
- Pitch Processing
- Filter
- Reverse
- Delay
- Pan
- Analog / Digital / Hybrid Modes
